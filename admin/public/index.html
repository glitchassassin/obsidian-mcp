Obsidian MCP

Private administration

Keep this admin UI on your trusted LAN. Never expose it publicly or route it through Cloudflare Tunnel.

Admin access

1. Obsidian account

2. Sync vault

Leave the encryption password empty for a vault using standard encryption. Selecting a vault locks this deployment to that account and vault.

3. MCP key

Copy this key into MCP Portal or your client's bearer credential. You'll only see it here once. If you lose it, generate a replacement.

4. Cloudflare Tunnel

Configure the tunnel's MCP route to http://obsidian-mcp.internal:8000/mcp. Never route it to the admin service.

5. Finish setup

This starts Sync, the MCP gateway, and the tunnel. Allow the initial vault download to finish before using MCP.
